# Contributing

Issues and small PRs are welcome.

- One focused change per PR, in as few lines as it honestly takes. Large or
  sweeping PRs will be asked to split.
- Write the PR description yourself, in your own words: what changed and why.
  Pasted AI summaries will be asked to be rewritten.
- The code rules — and what `npm test` enforces — live in [AGENTS.md](AGENTS.md). Run
  `npm test` and `shellcheck install.sh` before pushing.

Security problems: see [SECURITY.md](SECURITY.md).
